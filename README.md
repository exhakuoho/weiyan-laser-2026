## 一、接上 Google 試算表（約 5 分鐘，只需做一次）

1. 到 Google 雲端硬碟新增一份試算表，例如命名「8 大科學原理常態班 報名資料」。
2. 試算表上方選單 **擴充功能 → Apps Script**。
3. 刪掉編輯器裡原本的內容，貼上 `google-apps-script/Code.gs` 的全部內容，按 💾 儲存。
   - 想要「有人報名就寄信通知」：把 `NOTIFY_EMAIL = ''` 改成你的信箱。
4. 右上角 **部署 → 新增部署作業**：類型「**網頁應用程式**」、執行身分「**我**」、誰可以存取「**所有人**」。
5. 按「部署」並授權（出現「Google 尚未驗證這個應用程式」→ 進階 → 前往（不安全）→ 允許；這是你自己的程式，屬正常流程）。
6. 複製「網頁應用程式網址」（`https://script.google.com/macros/s/……/exec`），
   **先貼到瀏覽器打開**，看到「8 大科學原理常態班報名接收程式運作中」才算部署成功。
   （網站送出時看不到試算表端的錯誤，網址貼錯也會顯示「報名成功」，這一步一定要確認。）
7. 打開 `index.html`，搜尋 `SHEET_WEBHOOK_URL: ''`，把網址貼進引號中。
8. 測試：在網站送出一筆報名 → 試算表會自動出現「報名資料」分頁和一列資料。
   **測試完把那一列的「處理狀態」改成「測試」（或直接刪掉那一列）**，否則它會佔掉一個名額。

> 早鳥價由試算表端用 Google 伺服器時間重新判斷。改截止日或價格時，`index.html` 的 `CONFIG`
> 和 Apps Script 開頭的 `EARLY_BIRD_DEADLINE`、`PRICE_*` 兩邊都要改。
> 修改 Apps Script 後要用 **部署 → 管理部署作業 → 編輯 → 版本選「新版本」** 重新部署，網址才會維持不變。

## 二、試算表欄位

收到時間｜報名編號｜報名類型（報名整期／試聽一堂）｜課程｜學生姓名｜年級｜就讀學校｜家長姓名｜家長電話｜
緊急聯絡人｜緊急聯絡電話｜付款方式｜應繳金額｜早鳥｜得知管道｜備註｜瀏覽風格｜個資同意｜整期報名序｜處理狀態｜管理備註

- **整期報名序**：收到這筆時，它是第幾位有效的整期報名（不含取消／測試）。名額滿 12 位後，新報名的「處理狀態」會自動標成「候補（第 N 位）」。
  - 「處理狀態」含有 **取消** 或 **測試** 的列不算名額。有人取消：把處理狀態改成「取消」。
  - **只要還有人在排候補，新報名一律排到候補最後面**，不會插隊。名額釋出時，請打電話給候補第 1 位，
    確認後把他的處理狀態改成「已錄取」（任何不是「候補（」開頭的文字都算佔名額）。
  - 已寫入的序號與候補順位不會自動重排；遞補後候補順位以你手動處理為準。
- 「處理狀態」「管理備註」留給你手動更新（例如：已聯繫、已付款）。

## 三、網站上可調整的設定（`index.html` 最下方 `CONFIG`）

| 設定 | 目前值 | 說明 |
|---|---|---|
| `EARLY_BIRD_DEADLINE` | 2026-11-30 23:59:59 | ⚠️ 暫定，比照自走車班；過了之後自動改顯示原價、隱藏倒數 |
| `PRICE_ORIGINAL` / `PRICE_EARLY` | 4800 / 4200 | 原價／早鳥價 |
| `CAPACITY` | 12 | 每班人數上限（頁面上的 12 個座位圖示）；Apps Script 開頭也有一個 `CAPACITY`，兩邊要一致 |
| `START_DATE` | 空白 | 填入後取代「開課日期確定後公告」，例：`'2026/12/02（三）開課'` |
| `MAP_URL` | 空白 | 強納森美語教室的 Google 地圖分享連結；填入後才會出現「在 Google 地圖查看」 |

> ⚠️ 價格與人數除了 `CONFIG`，頁面文字裡也有寫死的地方，改的時候請在 `index.html` 搜尋並一起改：
> - 價格：搜尋 `4,200`、`4,800`、`600`（首屏價格標籤、「現省 NT$600」、原價列、手機下方按鈕、`<meta>` 說明）
> - 人數：搜尋 `12 人`（數字區、上課資訊、FAQ、頁尾；`story.html` 結尾也有）
> - 早鳥截止日：頁面上的日期文字會自動跟著 `CONFIG` 變，但 `<meta name="description">` 與 og 描述寫的是「早鳥 NT$4,200」，早鳥結束後建議改掉，以免 LINE 分享預覽顯示舊價格。
